# Diggy Diggy Sand

Gioco incrementale 3D per browser (HTML/CSS/JS ES modules + Three.js r160 in `vendor/`).

## Avvio
```
python -m http.server 8080
```
Poi apri http://localhost:8080. Debug: `?ending=curse|treasure|business`, `?cheat=1`.

Regole di progetto: `AGENTS.md`. Documenti di design: `Ideas/`.
